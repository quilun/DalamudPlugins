# Quilun's Dalamud Plugins

FFXIV plugins by Quilun, installable through Dalamud.

## Adding this repository
1. Type `/xlsettings` in game and open the **Experimental** tab.
2. Under **Custom Plugin Repositories**, paste this URL, click **+**, and save:
   ```
   https://raw.githubusercontent.com/quilun/DalamudPlugins/main/repo.json
   ```
3. Open `/xlplugins` and install the plugins you want.

## Plugins
- **[GlamImport](https://github.com/quilun/GlamImport)**: paste a glam from Eorzea Collection and apply it with Glamourer, or save it as a Glamourer design. Requires Glamourer.
